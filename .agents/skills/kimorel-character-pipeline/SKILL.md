## Activation Contract

Load for kimorel character v2, semantic retargeting, weights, glb export and migration qa. Apply the local adoption policy before consulting historical examples.

## Hard Rules

- Read the local contract map and current task authority before proposing changes. This skill encodes engineering invariants, not permission to export, approve anatomy or complete migration.
- Preserve frozen v1 assets and 34 source inputs, earlier v2 attempts and original pilots. Never refresh a baseline to conceal changes. Use new, non-overwriting variant paths and retain failed diagnostics.
- Map joints by unique semantic names; preserve canonical rep/hold identity, source profiles, source hashes, coordinate conversions, action slots and declared root/contact corrections. Never substitute index positions across rigs.
- Preserve native named weights including tiny positive influences, exact neutral geometry/topology/order, non-skin bytes outside explicitly allowed edits, morph envelopes and remote skin fields. Do not normalize/prune lossy loader output as source truth.
- Keep the unchanged 6× posed/rest edge sanity limit over all eligible edges and phase-specific contact gates; neither is anatomy approval. Do not tune thresholds until a candidate passes.
- Use only verified exports for activation; a 100-ID inventory or six checked candidates is not 100 completed exports. Preserve v1 fallback/rollback and pending human/device flags.

## Decision Gates

| Task              | Required evidence                                                                                                      |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Retarget/export   | Immutable body/cache/native-proof identity, declared source/profile, semantic transforms and actual clip identity.     |
| Weight correction | Original native proof, bounded authorized support, exterior/non-skin preservation and independent corruption fixtures. |
| Promotion         | Actual GLB QA plus scoped visual/contact evidence; keep anatomy/clinical/device acceptance separate.                   |

## Execution Steps

1. Inspect the current scope and immutable input contract; reuse the processed body, not a per-clip rebuild or generic rigging preset.
2. Propose isolated outputs and rollback before an authorized edit/export; load Blender core and asset QA when applicable.
3. Independently parse actual GLBs, validate raw attributes before loader normalization, verify named weights/provenance and topology, then sample canonical trajectories, morphs and real skinned surface contacts.
4. Preserve rep loop closure versus hold semantics and exercise-specific soles, forefeet, palms, rigid grips, supports and clearance. Inspect actual reimported views with exact asset hashes.
5. Run the relevant existing validator and its negative fixtures, then the read-only frozen-v1 checker; report rejected/pending IDs honestly.

## Output Contract

Return changed paths, exact checks and observed outcomes, pending evidence, and rollback scope. Separate measured facts from assumptions; do not claim safety or approval from a skill.
