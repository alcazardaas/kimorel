Human movement, openly animated.

Kimorel is a static, self-hostable TypeScript library with a React/Three.js viewer. The catalog includes fifty original standing, seated, dumbbell and floor movement GLBs using one character and rig. Browser/visual approval is pending; no clinical validation is claimed.

Run locally

Use the exact runtime in .nvmrc, install the pinned pnpm in package.json, then run pnpm install and pnpm dev.

Package boundaries

@kimorel/schemas owns validation and inferred types. @kimorel/core owns framework-independent utilities. @kimorel/data owns the catalog. @kimorel/react resolves stable exercise IDs or host-supplied metadata and loads independently hosted GLBs.

Contribute responsibly

Run lint, formatting, type checks, tests, metadata validation and build before requesting review. Do not submit assets without verified redistribution rights. Original software uses MIT; original example metadata is CC0.
